Reference & Troubleshooting

Frequently Asked Questions

Clear details about map costs, GPS permissions, mobile installation, and cloud database setup.

Do I need to pay for maps or GPS routing on live deployment?

No, you do NOT need to pay anything. The map architecture uses OpenStreetMap tiles and OSRM (Open Source Routing Machine), both of which are 100% free and open-source. Spoken turn-by-turn directions use the native Google Maps app deep-link, which requires no Google Cloud billing.

Why is HTTPS (SSL) required on live servers for GPS?

Modern web browsers (Safari, Chrome, Android, iOS) block location permissions on unencrypted http:// websites. When deployed to Vercel or modern cloud hosting, free SSL (https://) is enabled automatically so device GPS operates without issues.

How do riders install the app on Android phones?

Couriers can download the packaged APK directly from /regasco-app.apk, or open https://regasco.vercel.app/rider in Chrome and select "Add to Home screen" for a one-tap app launcher.
